BRB 1.0.0 · Автообновление через GitHub Releases · Windows x64

Запуск: закройте предыдущую копию BRB, полностью распакуйте архив в отдельную папку и запустите BRB.exe. Не удаляйте папку messaging. Если в прежней папке был ваш одобренный Discord SDK или собственный App ID, сохраните их: архив не настраивает Discord за вас.

Новое: аватар справа вверху → Настроить профиль. Измените имя, статус, цвет и портрет (включая свою картинку). Предпросмотр показывает результат до сохранения. Для ввода с геймпада доступна клавиатура РУС / ENG / 123. Профиль остаётся на этом ПК и не меняет аккаунт Steam. Проверены сохранение и восстановление данных, отмена, пустое имя, загрузка картинки, повтор после ошибки записи и отображение при следующем входе.

Автообновление: Настройки → Система → Обновление BRB. Нужен доверенный публичный репозиторий с реальными стабильными релизами. Без источника приложение не загружает обновлений. См. UPDATES-RU.txt. Сборка Windows x64, проверка SHA-256, обработка ошибочных релизов и экран настройки проверены; тесты сетевого канала используют имитацию ответов GitHub, а не публикацию реального релиза.

Что попробовать
1. Откройте библиотеку EA, затем Ctrl+K. Поиск теперь ищет среди установленных игр всех платформ, а Esc / B вернёт прежний запрос и вкладку. Неустановленные игры своего Steam-аккаунта по-прежнему ищите на полке Steam.
2. Нажмите Home → Загрузки. Сводка Steam сохраняет последнюю прочитанную очередь при временной ошибке и помечает её как неактуальную. В рабочей области Steam / EA нажмите «Назад в BRB» или отпустите и удерживайте B / ○ около 1,2 секунды на поддерживаемом SDL-контроллере. Жест действует только при фокусе BRB или основного окна клиента. Если открыто отдельное окно входа/подтверждения, сначала закройте его. Загрузка от возврата не отменяется. Кнопки самого клиента доступны мышью и клавиатурой.
3. Нажмите F1 или Home → «Помощь и состояние». Видны режим запуска, состояние библиотеки и обнаруженный геймпад. Отсюда можно перейти в загрузки и тест контроллера.
4. При долгом поиске игр можно войти и пользоваться остальными разделами. Ошибка чтения библиотеки больше не выглядит как успешная пустая библиотека: в уведомлении есть «Повторить». Повторные нажатия запуска игры и обновления списка объединяются на время запроса. Геймпад не перемещает меню, пока BRB не в фокусе.
5. В чате Steam / Discord ввод не теряется из-за фоновой проверки статуса. «Убрать из галереи» освобождает открытое медиа в BRB, не удаляя файл с диска.

Сохранения
Настройки и ярлыки остаются в %APPDATA%\OrbitLauncher. При следующем изменении BRB сохраняет предыдущую корректную версию library.json в library.json.bak. При повреждении основного файла повреждённый оригинал сохраняется под именем library-damaged-*.json. Если исправной копии нет, BRB начинает с пустых настроек и ищет установленные игры заново; ручные ярлыки может потребоваться добавить повторно. Если данные не удаётся безопасно сохранить, BRB не заменяет нечитаемый файл. Второй запуск этой версии в том же сеансе Windows не создаёт конкурирующую копию.

Объём проверки
Проверены сборка Windows x64, Go-тесты с детектором гонок на Linux, Windows go vet, сценарии интерфейса в Chromium, тесты адаптеров Steam с фиктивными ответами. Проверены загрузочная сцена, возврат и фокус, окно загрузок и ошибки, режимы тачпада, 13 категорий настроек, тест контроллера, медиагалерея, Steam-библиотека, профиль и достижения, отображение иконок EA, отправка сообщения при одновременном обновлении списка. Код удержания B проверен с имитацией SDL.

Что проверить на реальном ПК
• В Steam поставить на паузу и продолжить небольшую загрузку; сверить результат в самом клиенте. В EA — открыть диспетчер загрузок, выполнить те же действия. Проверить, что «Назад в BRB» не прерывает загрузку и возвращает исходное размещение окна.
• Подключить физический контроллер по USB / Bluetooth, проверить выбор в меню, движение круга, возврат из клиента и отсутствие нажатий после Alt+Tab.
• Для онлайн-функций нужны собственный вход Steam и, для Discord, разрешения/SDK. Автотесты не входили в реальные аккаунты, не отправляли реальные сообщения и не загружали игры.
